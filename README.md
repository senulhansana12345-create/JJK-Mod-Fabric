# JJK Premium Mod

A Fabric 1.21.1 Jujutsu Kaisen-inspired combat mod prototype with:
- sorcerer selection system
- Gojo Six Eyes / Limitless showcase
- domain-based combat features
- player progression and detail panels
- admin commands
- PvP-ready structure for expansion

## Features in this starter build
- configurable sorcerer registry
- technique registry and descriptions
- player profile system with level and cursed energy
- domain activation flow
- custom JJK GUI screens
- /jjk admin command set

## Run locally
1. Install JDK 21
2. Run:
   ./gradlew genSources
   ./gradlew runClient

## Important scope note
This is a functional starter mod foundation inspired by JJK, intentionally structured to be extended with more characters, techniques, visuals, and advanced domain systems.
